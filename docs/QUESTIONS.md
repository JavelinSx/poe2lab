# Вопросы игрока, на которые poe2lab отвечает сам

Список собран из реальных вопросов по билду (Flicker Invoker, 2026-10-01). Каждый вопрос — то, что игрок
должен видеть без вопроса: где в poe2lab ответ и чем он посчитан.

| Вопрос | Где ответ | Как считается |
|---|---|---|
| Почему поддержки срабатывающего скилла «почти без эффекта»? | «Скиллы» → вклад поддержки «за одно срабатывание» | урон одного удара (PoB) вместо DPS, части скилла по атрибутам (`analysis.skills`) |
| Как работают мета-камни, как часто срабатывают? | «Скиллы» → ⚡ в группе и «🔍 Как устроен билд» | энергия за событие × сила монстра, босс / толпа (`analysis.triggers`) |
| Когда на самом деле переходить на билд? Откуда заряды, дух? | «Обзор» → «Как качаться до билда» | цепочка: баффы, источники зарядов, бюджет духа, снимок билда на уровне N (`analysis.leveling`) |
| Почему скилл съедает ману, что поможет? | «🔍 Как устроен билд» → 💧 Мана | расход / регенерация / похищение по типам урона, поддержки, которые закрывают дефицит (`analysis.explain`) |
| Насколько обязателен уник, когда его надевать? | «Снаряжение» → слот → «🎯 Что важно в слоте» | уник против лучшей редкой вещи из реальных модов; снимок по уровням (`analysis.slotadvice`) |
| Как разогнали крит, урон крита, скорость, защиту? | «🔍 Как устроен билд» | источники модификаторов PoB по группам и условиям (`analysis.explain`) |
| Как работает отклонение, что даёт 13% против 22%? | «🔍 Как устроен билд» → 🛡, «Что важно в слоте» | рейтинг отклонения и шанс по формуле PoB; цена мода в EHP |
| Какие статы важны на посохе (перчатках, нагруднике…)? | «Снаряжение» → слот → «🎯 Что важно в слоте» | каждый мод слота в составе хорошей вещи (верхний тир, средний ролл) и лучшая вещь 3 + 3 |
| Зачем билду этот стат? («билд на стихиях → оружие → стихийный урон», «броня → уклонение → отклонение») | «🎯 Что важно в слоте» → 🧭 Зачем | из чего состоит удар, связки PoB между статами (`GainAs`, `ConvertTo`) с источниками, защита; виды модов, которые слот оплачивает больше всего |
| Откуда в ударе холод, если в описании скилла его нет? | «🎯 Что важно в слоте» → 🧭 Зачем → «откуда?» | по каждому типу урона: урон оружия, добавленный вещами и пассивками, «урон как дополнительный …» с источниками, увеличение и «больше» (`analysis.slotadvice.facts`) |
| Что мне брать, чтобы идти к билду, а не к тому, что надето? | «🎯 Что важно в слоте» (персонаж в билде) | рейтинг, «зачем» и лучшая вещь — на гайде, из баз и тиров уровня персонажа; лучшая вещь ещё и на персонаже против надетой |
| Сколько стоит такая вещь, как её скрафтить? | «🎯 Что важно в слоте» → ⚒ Как скрафтить, 💰 Цена на рынке | симулятор крафта по модам лучшей вещи (`crafting`), один поиск на рынке по 4 самым ценным модам, найденное — на билд через PoB (`economy.trade`) |
| Как мне эта вещь с рынка? | «Создать вещь» → Ctrl+V | копия с рынка RU/EN, вердикт и урон каждого скилла для оружия |
